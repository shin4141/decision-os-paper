# Decision-OS V5 / SiriusA

V5 proposes a confirmation layer for irreversible human–AI decisions. The revised paper adds trajectory-aware pressure signals, the Adoption Gate, zero-knowledge authorization, trusted-party confirmation, and independent non-score stop conditions. These are research-design claims, not a claim that the linked demo implements the entire architecture.
