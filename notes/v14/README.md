# Decision-OS V14 Research Note

## Resource Justice at the Joint Layer

V14 asks whose finite judgment resources are consumed when continuation fails. The **joint layer** is a transfer point across sessions, agents, tools, files, or repositories where state, decision rights, evidence time, and responsibility must continue together.

It distinguishes remembering information from inheriting responsibility. Failure modes include returning unresolved reconstruction or verification work to the human, treating past and current state as interchangeable, and protecting the wrong decision object.
