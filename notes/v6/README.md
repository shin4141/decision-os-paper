# Decision-OS V6 / PIC

V6 defines conditions for non-destructive integration at a commitment boundary: admissible updates, order-robust merge, bounded canonicalization, and conservative safety aggregation. PIC means Phase-Invariant Core. Its formal results depend on the stated invariants and assumptions; it does not define a complete memory product or prove self-evolution.
